# Luau Notes
แอปโน้ตเก็บสคริป Luau (ตั้งชื่อ/เปลี่ยนชื่อ/ทำสำเนา/ลบ/ค้นหา/คัดลอก/วาง/แชร์) เก็บข้อมูลในเครื่องเท่านั้น

## วิธีได้ APK
1. อัปโฟลดโฟลเดอร์นี้ขึ้น GitHub repo
2. แท็บ Actions -> Build APK -> รอจนเสร็จ -> โหลด Artifact "LuauNotes-debug-apk"
หรือเปิดด้วย Android Studio แล้ว Build > Build APK
